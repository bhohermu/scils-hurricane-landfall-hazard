# Changelog

## 0.1.0 - 2026-04-20

- Prepared the codebase for an initial public repository release.
- Added packaging metadata for the `scils-tc` installable project.
- Renamed the Python package from `src` to `scils_tc`.
- Added Apache 2.0 licensing and software citation metadata.
- Added batch entrypoints for preprocessing, detrending, simulation, and resampling.
- Hardened repository hygiene so raw ERA5 and IBTrACS inputs and generated outputs are excluded from version control.
- Added public-release documentation for installation, data access, and release workflow.
