# Data Access

This repository is code-first. The public repository does not version the full raw input datasets used by the model.

## Included in the repository

| File | Description | Source |
|------|-------------|--------|
| `data/RONI.csv` | Niño-3.4 anomaly time series used for ENSO classification | NOAA Climate Prediction Center |
| `data/regionDefinitionsJewson.csv` | Tropical cyclone landfall region polygon definitions | Jewson (2023), doi:[10.1175/BAMS-D-22-0189.1](https://doi.org/10.1175/BAMS-D-22-0189.1) |
| `data/tl_2023_us_state/` | US state boundary shapefile (TIGER/Line 2023) | US Census Bureau (public domain) |
| `data/YELT_STORM_present_NA_10000_YEARS.csv` | Year Event Loss Table for the North Atlantic, generated with CLIMADA using the STORM present-day 10 000-year track set (Bloemendaal et al., 2020) | See YELT provenance below |
| `tests/fixtures/` | Lightweight regression-test fixtures generated by `tests/generate_fixtures.py` | Derived from model outputs |

## YELT provenance

The YELT was generated using the open-source risk assessment model CLIMADA (Aznar-Siguan and Bresch, 2019). CLIMADA estimates impacts based on hazard, exposure, and vulnerability. The hazard component uses the STORM present-day track set (10 000 years, representing 1980–2018 climate; Bloemendaal et al., 2020) with a parametric 2-D wind field (Holland, 2008). Exposure is modelled with LitPop (Eberenze et al., 2020) and vulnerability with the regional impact functions from Eberenz et al. (2021). Direct economic damages are computed at 300 arc-second (~10 km) resolution.

- STORM dataset: Bloemendaal et al. (2020), doi:[10.1038/s41597-020-0381-2](https://doi.org/10.1038/s41597-020-0381-2); data: https://doi.org/10.4121/uuid:82c1dc0d-5571-4e84-9bb9-e9511c7e4608
- CLIMADA: Aznar-Siguan and Bresch (2019), https://github.com/CLIMADA-project/climada_python
- Parametric wind model: Holland (2008)
- Exposure (LitPop): Eberenz et al. (2020)
- Vulnerability (regional impact functions): Eberenz et al. (2021)

## Excluded from the repository

- ERA5 raw inputs (see below)
- IBTrACS raw input file
- Generated outputs under `preprocessed/`, `detrended/`, `simulated/`, and `resampled/`

## External raw-data directory

The model expects raw ERA5 and IBTrACS data under a separate directory. By default this is `external-data/` relative to the repository root. Override it with the `SCILS_TC_RAW_DATA_DIR` environment variable.

### Required ERA5 files

All ERA5 files are monthly means downloaded from the Copernicus Climate Data Store (CDS). A sample CDS API request will be added in a later release.

| File (under `ERA5/`) | Variables | Levels | Period | Spatial extent |
|-----------------------|-----------|--------|--------|----------------|
| `ERA5_monthly_1980_2025_SST_MSLP_lsm.nc` | `sst`, `msl`, `lsm` | Single level | Monthly, 1980–2025 | 0–65°N, 100°W–10°E, 0.25° |
| `ERA5_monthly_1980_2025_U_V_850_200hPa.nc` | `u`, `v` | 850 & 200 hPa | Monthly, 1980–2025 | 0–65°N, 100°W–10°E, 0.25° |
| `ERA5_monthly_1980_2025_t_1000to50hPa.nc` | `t` | 1000–50 hPa | Monthly, 1980–2025 | 0–65°N, 100°W–10°E, 0.25° |
| `ERA5_monthly_1980_2025_q_1000to50hPa.nc` | `q` | 1000–50 hPa | Monthly, 1980–2025 | 0–65°N, 100°W–10°E, 0.25° |

These files cover the North Atlantic domain and are used to compute SST, wind shear, potential intensity (PI), and the convective genesis index (CGI).

### ERA5 GWL files (under `data/GWL/`)

Used to compute the Global Warming Level (GWL) following the C3S methodology.

| File | Variables | Period | Spatial extent |
|------|-----------|--------|----------------|
| `era5_2mTemperature_1951_2025.nc` | `t2m` | Monthly, 1951–2025 | Global, 0.25° |
| `era5_2mTemperature_anomalies_1991_2020/*.grib` | `t2m` climatology | 1991–2020 (12 monthly files) | Global, 0.25° |

### IBTrACS

| File | Description |
|------|-------------|
| `IBTrACS.NA.v04r01.nc` | International Best Track Archive, North Atlantic, v04r01 |

Expected directory layout:

```text
external-data/
  ERA5/
    ERA5_monthly_1980_2025_SST_MSLP_lsm.nc
    ERA5_monthly_1980_2025_U_V_850_200hPa.nc
    ERA5_monthly_1980_2025_t_1000to50hPa.nc
    ERA5_monthly_1980_2025_q_1000to50hPa.nc
  IBTrACS.NA.v04r01.nc
```

The GWL files are expected under `data/GWL/` inside the repository (gitignored).
